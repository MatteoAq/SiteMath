# SiteMath – матрицы

Небольшой автономный учебный сайт для подготовки к контрольной по теме «Матрицы».

Внутри есть:
- базовая теория от размеров матриц;
- калькулятор матричных выражений с промежуточными шагами;
- определители 2×2, 3×3 и числовые квадратные матрицы большего порядка;
- уравнения и неравенства вида `det(A(x)) = 0`, `det(A(x)) > 0` для линейных по `x` элементов;
- ранг методом Гаусса;
- тренажёр с проверкой ответов;
- примеры по листку преподавателя;
- краткая шпаргалка.

Сайт не требует сервера: `index.html` можно открыть локально в браузере.
