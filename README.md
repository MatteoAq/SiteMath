# SiteMath

Интерактивный пошаговый построитель для задания №3 по начертательной геометрии:

> Через точку C провести прямую ℓ, пересекающую отрезок прямой AB, и прямую a, параллельную AB.

Сайт принимает произвольные координаты A, B и C, строит комплексный чертёж в системе двух плоскостей проекций и показывает построение по шагам: ось x₁₂, линии связи, A₁/A₂, B₁/B₂, C₁/C₂, проекции AB, параллельную a и пересекающую ℓ.

Особенности:
- масштаб 1:1, одна клетка = 5 мм = 0,5 см;
- анимация карандаша и линейки;
- для каждого шага объясняется, что отмерять и почему;
- свободная точка пересечения K внутри AB настраивается ползунком;
- проверяются вырожденные и невозможные наборы координат;
- печать / сохранение в PDF.

GitHub Pages: https://matteoaq.github.io/SiteMath/
