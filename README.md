# SiteMath

[Открыть SiteMath](https://matteoaq.github.io/SiteMath/)

Интерактивный пошаговый построитель для задач по начертательной геометрии. В банке находятся 20 вариантов университетского альбома, по шесть заданий в каждом.

## Возможности

- Задание 1: комплексный чертёж и наглядное изображение точек на трёх плоскостях проекций.
- Задание 2: натуральная величина отрезка и его углы наклона к плоскостям проекций.
- Задание 3: построение прямой через точку, пересекающей заданный отрезок, и параллельной прямой.
- Задание 4: горизонталь, фронталь, линия наибольшего ската плоскости и дополнительное условие варианта.
- Задание 5: пересечение прямой с плоскостью и определение видимости.
- Задание 6: линия пересечения двух плоскостей и прямая, параллельная обеим плоскостям.

Построение показывается последовательно, с описанием действия, обоснованием и доступными размерами. Чертёж можно увеличить, переместить и приблизить к текущему шагу. Интерфейс поддерживает телефон и ПК.

Оригиналы всех 20 вариантов находятся в [каталоге сканов](source-photos/scans/). Для задач 1–3 исходные координаты берутся из условий; для задач 4–6 графические данные перенесены с соответствующих листов. Сетка имеет шаг 5 мм.

## Точность

Все 20 вариантов проходят автоматические проверки условий и алгоритмов. Для 18 вариантов (01–11, 14–20) сохранены проверенные графические решения по исходным рисункам. В 12/6 и 13/5 с разрешения пользователя сделаны **учебные реконструкции**, сохраняющие узнаваемость и геометрические связи, но изменяющие наклоны исходных штрихов. Они не являются метрическими копиями университетского растра; оригиналы сохранены отдельно. В заданиях 4–6 преподаватель не даёт числовых координат, а числа в JSON описывают цифровой рисунок.

## Исходный код и проверки

Сайт работает статически, без сервера приложений. Интерфейс находится в `index.html` и `styles.css`, алгоритмы в `multi.js`, данные вариантов в `data/variants/XX.json` (файл `variants.js` генерируется автоматически). Для пересборки данных: `node scripts/build-variants.mjs`. Основные автоматизированные проверки находятся в `tests/`; GitHub Actions запускает тесты геометрии, этапов построения и адаптивной вёрстки.

Подробности об ограничениях и проверках: [Геометрия и QA](docs/GEOMETRY_AND_QA.md). Соответствие типов линий преподавательской теме «Линии» отдельно разобрано в [аудите графических обозначений](docs/DRAFTING_LINES_AUDIT.md).
