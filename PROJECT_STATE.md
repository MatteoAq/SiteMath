## 2. Основная цель

Сайт должен быть не просто математическим калькулятором, а **пошаговой решалкой, по которой студент может вручную воспроизвести чертёж и объяснить преподавателю происхождение каждой линии и точки**.

Для №4–6 правильность конечного ответа недостаточна. Обязательна правильная последовательность ручного построения:
1. каждый новый объект либо дан на исходном листе;
2. либо точка явно выбирается на уже существующем объекте;
3. либо получается пересечением;
4. либо получается линией связи/проецированием;
5. либо строится по параллельности/перпендикулярности;
6. либо является явно введённой вспомогательной линией/плоскостью.

Запрещено показывать точки или линии, происхождение которых пользователь не видел на предыдущем шаге.

## 3. Неподвижные правила для заданий №4–6

### 3.1. Исходный чертёж с бумажного листа

Первый кадр задания должен повторять бумажный оригинал конкретного варианта:
- те же исходные линии;
- те же исходные точки;
- те же подписи;
- те же проекторы/линии связи, если они напечатаны;
- те же способы задания плоскостей;
- та же топология и относительное положение.

Нельзя подменять бумажный чертёж «похожей схемой того же типа».

Исходная трассировка и математическая геометрия решателя – разные сущности:
- **source/raw geometry** нужна для первого кадра и должна сохранять бумажный источник;
- **solver/clean geometry** может исправлять погрешность фотографии/трассировки для вычислений: параллельность, общий проектор пересекающихся пространственных прямых и т.п.;
- очистка решателя не должна незаметно менять исходный кадр.

## 4. Методика задания №4

Нужно построить горизонталь, фронталь, линию наибольшего ската и выполнить дополнительное условие конкретного варианта.

### Горизонталь

Для обычного случая с двумя реальными линиями плоскости:
1. явно выбрать `1₂` на уже существующей первой линии;
2. через `1₂` провести `h₂ ∥ x₁₂`;
3. только пересечение `h₂` со второй линией создаёт `2₂`;
4. линиями связи получить `1₁`, `2₁`;
5. соединить их в `h₁`.

Критическая ошибка, которую уже находили: сайт раньше сразу рисовал `1₂` и `2₂` как готовые точки. Так делать нельзя.

### Фронталь

Аналогично:
1. явно выбрать `3₁` на существующей линии плоскости;
2. через неё провести `f₁ ∥ x₁₂`;
3. пересечение со второй линией даёт `4₁`;
4. линиями связи получить `3₂`, `4₂`;
5. построить `f₂`.

### Линия наибольшего ската

1. явно выбрать `S₁ ∈ h₁`;
2. провести `ЛС₁ ⟂ h₁`;
3. следующая точка должна получиться пересечением с существующей линией плоскости;
4. перенести её линией связи на вторую проекцию;
5. получить `ЛС₂`.

Нельзя создавать `S₁` и конечную ЛС одновременно одним скрытым аналитическим шагом.

### Частный случай «точка + прямая»

Если плоскость задана вида `Σ(A;a)`, ручная последовательность должна быть видимой. В частности, новая фронталь не должна появляться сразу по двум новым точкам – первая точка выбирается на уже построенной линии плоскости, вторая получается пересечением.

### Дополнительное условие

Если требуется прямая, пересекающая конкретную линию/горизонталь/фронталь:
1. сначала явно выбирается точка `T` на существующем целевом объекте;
2. затем через заданную точку и `T` строится `ℓ`.

Если дополнительное условие задаёт результирующую точку A:
1. должна быть явно введена вспомогательная опорная точка `N`;
2. A не должна появляться до шага с N.

## 5. Методика задания №5

Цель: пересечение прямой `ℓ` с плоскостью и определение видимости.

Полная ручная цепочка:
1. перенести исходную плоскость и `ℓ`;
2. провести рабочие оси;
3. заключить `ℓ` во вспомогательную проецирующую плоскость `Ω`;
4. получить точки `1/2` её пересечения с заданной плоскостью;
5. построить линию сечения `m`;
6. получить `K = m ∩ ℓ`;
7. построить конкурирующие точки `3/4` для Π₁;
8. построить конкурирующие точки `5/6` для Π₂;
9. только после этого нанести видимый/невидимый участки `ℓ`.

Видимость нельзя просто вычислить внутри solver и показать штриховую линию без построения конкурирующих точек.

## 6. Методика задания №6

Цель: линия пересечения двух плоскостей и прямая через заданную K/M, параллельная обеим.

Общий порядок:
1. перенести обе исходные плоскости и K/M;
2. рабочие оси/ориентиры;
3. если плоскость задана «точка + прямая», сначала явно достроить вторую линию внутри плоскости через выбранную `T` на исходной прямой;
4. явно выбрать вспомогательную секущую плоскость `α`;
5. построить её сечения обеих заданных плоскостей и получить общую точку `P`;
6. явно выбрать вторую секущую плоскость `β`;
7. аналогично получить `Q`;
8. соединить `P,Q` и получить `r = P Q`;
9. только после существования `r` провести через K/M искомую `ℓ`, параллельную обеим плоскостям.

Вспомогательные точки сечений `1–8` должны оставаться на итоговом чертеже, если они реально участвовали в ручном построении.
