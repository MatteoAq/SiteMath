## Важно: оригиналы были присланы, но не экспортированы

Отдельно в библиотеке сохранился оригинал **12**. Поэтому **не писать, что эти листы пользователь не отправлял**.

По состоянию на 08.10.2026 полный просмотр каталога Library изображений за сентябрь–октябрь, файлов из предыдущих доступных разговоров, Google Drive и деревьев GitHub обнаружил полноразмерный исходник только 12, а также учебный пример и фотографии/скриншоты обсуждения. **Файлы из партии 1 октября не обнаруживаются как доступные вложения, несмотря на их существование в прежнем чате.** В GitHub представлены миниатюры этой партии: `reference-screenshots/image(6).png`. Это не пригодный для точного считывания оригинал.

Нельзя утверждать, что другие варианты никогда не присылались, нельзя называть их перепроверенными по скриншотам и нельзя подменять реальные фотографии восстановленными геометрическими изображениями. **Для получения исходных файлов потребуется вновь предоставить изображения или перенести их в доступную папку через старый чат.** После восстановления каждый исходник должен быть загружен бинарно в GitHub под `source-photos/variant-NN/`, с сохранением имени и хеша. Файлы `variants.js` не являются резервной копией исходных фотографий.

Фотографии по химии, истории, праву, операционной системе и изображения чужих проектов не копировались в публичный репозиторий SiteMath.
