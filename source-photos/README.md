# Оригиналы задач SiteMath – актуальные сканы

**Актуально с 14.10.2026.** Канонические источники заданий всех **20 вариантов (01–20)** находятся в [`scans/`](scans/) – по одному полному сканированному листу с шестью заданиями. Все ссылки сайта на исходный лист ведут сюда, в том числе для числовых задач №1–3.

Сканы извлечены из университетского альбома «Задание № 1 Альбом из 6 задач (для очников).docx» в закрытом Google Диске пользователя. В оригинальном DOCX **26 листов**. DOCX и методичка преподавателя остаются в закрытом хранилище; в GitHub опубликованы только 20 листов соответствующих текущим вариантам SiteMath. 21–26 в рабочий калькулятор не добавлялись.

**Важно:** изображения `scans/variant-XX.jpg` являются полноразмерными по пиксельным размерам, но перекодированы из исходных RGB PNG в JPEG с оттенками серого и качеством 82, чтобы страница загружалась быстрее. Это НЕ побайтовые копии PNG из DOCX. Для доказуемой идентичности исходному изображению сохранены имя встроенного PNG и хэш уже опубликованного JPEG. Изображения сохраняют весь исходный лист; области заданий не вырезаны.

Ранее хранившиеся в `source-photos/variant-XX/` фотографии заданий заменены сканами и удалены из **актуального дерева** GitHub. При необходимости прежние JPEG доступны в истории Git, но источником для текущей версии сайта больше не являются. - В `variants.js` каждому из графических заданий №4–6 каждого варианта задан `sourceId=source-photos/scans/variant-XX.jpg` и `sourceAvailable=true`.
- В `tests/paper-originals.mjs` проверяются точные SHA-256 **20** текущих файлов, 60 численных заданий и 60 структур графических условий; проверка реальных бумажных источников сама по себе ещё не является независимым доказательством всех 817 этапов геометрических построений.
- `sourceGeometry` – исходная бумажная трассировка – отделена от согласованной вычислительной геометрии. **`sourceVerified=false`** сохраняется до отдельной полной методической проверки; это не означает отсутствие бумажного скана.
- Подтверждённые исправления, уже внесённые по оригиналам: **07/3** B.x=10; **13/1** D.x=40; **14/3** B.x=5; особые исходные подписи **11/6**, исходная прямая **f** в **20/5**, несоединённые исходные вершины в **20/4**.
